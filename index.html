CONVERSÃO DE BINÁRIO PARA DECIMAL (E VICE-VERSA)

Os computadores só entendem dois estados (ligado 1 ou desligado 0) porque funcionam com impulsos elétricos. Já nós, humanos, usamos a base 10 (decimal) porque temos 10 dedos nas mãos para contar.

De Binário para Decimal (Método do Varal Posicional)

Pense no sistema posicional como um varal. Cada posição de um dígito tem um peso que é sempre o dobro do vizinho da direita.

Vamos converter o binário 100101:

  • Escreva o número binário bem espaçado no papel: 1 0 0 1 0 1
  • Monte o "varal de potências de 2" acima dele. Comece pela direita com o número 1, e vá dobrando para a esquerda: 1, 2, 4, 8, 16, 32:
Varal (Pesos)32168421
Seu Número100101

Multiplique o número de cima pelo de baixo (ou simplesmente ignore onde tem 0 e guarde onde tem 1):

  • Tem 1 sob o 32 -> Guarda 32
  • Tem 0 sob o 16 -> Ignora (dá 0)
  • Tem 0 sob o 8 -> Ignora (dá 0)
  • Tem 1 sob o 4 -> Guarda 4
  • Tem 0 sob o 2 -> Ignora (dá 0)
  • Tem 1 sob o 1 -> Guarda 1

Some os números que você guardou: 32 + 4 + 1 = 37

Resultado: O binário 100101 é igual a 37 em decimal!

De Decimal para Binário (Método das Caixinhas - Sem fazer divisão!)

Você precisa descobrir como "construir" um número decimal usando apenas os tijolos do nosso varal (16, 8, 4, 2, 1). Vamos converter o número 13:

  • Desenhe as caixinhas de pesos de trás para frente até chegar a um número que passe de 13. O 16 é maior que 13, então não podemos usá-lo.
  • Agora, pergunte: "Quais desses números somados dão exatamente 13?"
    • Eu consigo usar o 8? Sim, porque 8 é menor que 13. (Ativamos o 8. Sobram 13 - 8 = 5 para completar).
    • Consigo usar o 4 para ajudar a completar os 5 que sobram? Sim, porque 4 é menor que 5. (Ativamos o 4. Sobra 5 - 4 = 1 para completar).
    • Consigo usar o 2 para completar o 1 que sobra? Não, porque 2 passa de 1. (Deixamos o 2 desligado).
    • Consigo usar o 1? Sim, porque precisamos de exatamente 1. (Ativamos o 1).
Peso8421
StatusUsado (1)Usado (1)Fora (0)Usado (1)

Resultado: O número decimal 13 em binário é 1101!

(Se preferir o método de dividir sucessivamente por 2, você divide o número e anota o resto. Se for ímpar, o resto é 1; se for par, é 0. Ao final, lê os restos de trás para frente.)

CONVERSÃO DE BASE OCTAL

O sistema octal usa apenas 8 dígitos (de 0 a 7). Os números 8 e 9 não existem aqui.

De Octal para Decimal (Multiplicar por 8)

Funciona igual ao binário, mas em vez de dobrar de 2 em 2, as posições aumentam multiplicando por 8: 1, 8, 64, 512...

Vamos converter o octal 371:

Varal (Pesos)64 (8x8)81
Seu Número371
Multiplicação3 x 64 = 1927 x 8 = 561 x 1 = 1

Some todos os resultados: 192 + 56 + 1 = 249

Resultado: O octal 371 equivale a 249 em decimal.

De Decimal para Octal (Divisões por 8)

Aqui nós dividimos o número decimal por 8 sucessivamente até o quociente ser 0, guardando sempre o resto da divisão. Vamos converter 177:

  • Passo 1: 177 ÷ 8 = 22 com resto 1 (pois 22 x 8 = 176, sobra 1).
  • Passo 2: Pegue o 22 e divida de novo: 22 ÷ 8 = 2 com resto 6 (pois 2 x 8 = 16, sobram 6 para chegar a 22).
  • Passo 3: Pegue o 2 e divida por 8: Como 2 é menor que 8, dá 0 com resto 2.

Escreva os restos de trás para frente: 2 6 1.

Resultado: 177 em decimal é 261 em octal!

💡 Macete Extra de Ouro: Octal para Binário Direto

Como 2³ = 8, cada 1 dígito em octal vira exatamente um grupo de 3 bits em binário. Use a colinha de peso de 3 bits: 4, 2, 1.

Vamos converter o octal 27 diretamente para binário:

  • Para o dígito 2: Qual das casas (4, 2, 1) eu ativo para somar 2? Apenas a casa do 2. Fica: 0 1 0.
  • Para o dígito 7: Quais casas eu somo para dar 7? Todas (4+2+1=7). Fica: 1 1 1.
  • Junte os dois blocos: 010 (do 2) + 111 (do 7) = 010111.

Resultado: O octal 27 é igual a 10111 em binário!

CONVERSÃO DE BASE HEXADECIMAL

O sistema hexadecimal usa 16 símbolos (0-9 e A-F, onde A=10, B=11, C=12, D=13, E=14, F=15).

De Hexadecimal para Decimal (Multiplicar por 16)

Vamos converter o hexadecimal 1FA (1 -> 1 | F -> 15 | A -> 10):

Varal (Pesos)256 (16x16)161
Seu Número1F (15)A (10)
Multiplicação1 x 256 = 25615 x 16 = 24010 x 1 = 10

Some os resultados: 256 + 240 + 10 = 506

Resultado: O hexadecimal 1FA equivale a 506 em decimal!

De Decimal para Hexadecimal (Divisões por 16)

Vamos converter 685:

  • Passo 1: 685 ÷ 16 = 42 com resto 13 (letra D).
  • Passo 2: Pegue o 42 e divida: 42 ÷ 16 = 2 com resto 10 (letra A).
  • Passo 3: Pegue o 2 e divida por 16: Como 2 é menor que 16, dá 0 com resto 2.

Leia os restos de trás para frente: 2, A(10), D(13).

Resultado: 685 em decimal é 2AD em hexadecimal!

💡 Macete Extra de Ouro: Hexadecimal para Binário Direto

Como 2⁴ = 16, cada 1 dígito em hexadecimal vira exatamente um grupo de 4 bits em binário (8, 4, 2, 1). Vamos converter 1B (B vale 11):

  • Para o dígito 1: Apenas a casa do 1 fica ativa. Fica: 0 0 0 1.
  • Para o dígito B (11): Quais dessas casas eu somo para dar 11? 8, 2 e 1 (8+2+1=11). Fica: 1 0 1 1.
  • Junte os blocos: 0001 (do 1) + 1011 (do B) = 00011011.

Resultado: O hexadecimal 1B equivale a 11011 em binário!
